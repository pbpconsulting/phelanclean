# Phelan Clean — initial responsive website

## Stack
HTML + CSS + minimal vanilla JavaScript. No framework, database or CMS.

## Pages
- index.html — Home
- services.html — Services
- pricing.html — Pricing
- about.html — About
- quote.html — Get a Quote

## Responsive
The site is designed for desktop/laptop, tablet and mobile from the start. CSS breakpoints collapse the navigation and reflow the grids at 900px and 600px.

## Images
All current images are deliberately placeholders. Replace the SVG files with the final Phelan Clean photography once the layout is approved.

The current logo is also a placeholder. Replace `images/logo-placeholder.svg` with the supplied final logo and update the two references if required.

## Quote form
The form is deliberately not connected yet. Once the existing Phelan site form technology is confirmed, the form action/fields can be connected without rebuilding the page.

## Run
Open this folder in VS Code and launch `index.html` with Live Server.
